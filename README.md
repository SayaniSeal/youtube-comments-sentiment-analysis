# YouTube Comments Sentiment Analysis

This project fetches YouTube comments from a video and performs sentiment analysis using the VADER Sentiment Analysis model. It also includes various visualizations to showcase the sentiment distribution, such as bar charts, pie charts, and word clouds.

## Features
- **Fetch YouTube Comments**: Extracts top-level comments from a YouTube video using YouTube Data API v3.
- **Sentiment Analysis**: Classifies comments as positive, negative, or neutral based on their sentiment score.
- **Visualizations**: Displays sentiment distributions using bar charts and pie charts. Also generates word clouds for positive, negative, and neutral comments.
- **Comment Filtering**: Filters out irrelevant comments, such as those with links or emojis only.
